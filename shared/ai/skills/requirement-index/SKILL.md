# Requirement Index Skill
This skill provides a searchable index of all project requirements as a lightweight JSON file.

The index is AUTO-GENERATED by the server whenever requirements change. Do NOT modify it manually.

## File Location
The index file is at `references/index.json`. It is regenerated automatically when requirements are saved or deleted.

## Index Entry Format
Each index entry contains:
- id: requirement ID (string)
- title: requirement title (string)
- level: hierarchy depth (0=epic, 1=feature, 2=story, 3=ac)
- parent: parent requirement ID (string or null)
- summary: first 200 characters of the description (string)
- tags: extracted keyword tags (string array, e.g., ["auth", "login"])
- priority: CRITICAL|HIGH|MEDIUM|LOW
- testType: inferred test types (string array, e.g., ["functional", "security", "ui"])
- childCount: number of direct children (integer)
- children: array of child requirement IDs (string array)

## How to Use This Index
1. First, read `references/index.json` to understand the requirement landscape
2. Identify epics (level=0) as top-level batch boundaries
3. Use the `requirement-query` skill for filtering strategies
4. NEVER load all requirements at once — always filter a relevant subset first

## Regeneration Trigger
This index is regenerated whenever:
- A requirement is saved (created or updated)
- A requirement is deleted
- Requirements are imported in bulk

The regenerated file is written to this skill's `references/index.json` automatically.
