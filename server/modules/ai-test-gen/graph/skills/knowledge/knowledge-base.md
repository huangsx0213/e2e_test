# Knowledge Base

> This is a placeholder for the knowledge base skill. Add your domain-specific knowledge files here.

## Supported Knowledge Types

- **Business Rules** — Domain-specific business logic and constraints
- **Common Knowledge** — Industry standards, regulations, best practices
- **Historical Test Cases** — Patterns from past testing efforts
- **Bug Patterns** — Common defect categories and root causes
- **Domain Glossary** — Terms and definitions specific to the project

## How to Add Knowledge

1. Create a new `.md` file in this directory with a descriptive name
2. Follow the naming convention: `{type}-{name}.md` (e.g., `business-rule-payment-thresholds.md`)
3. Use clear headings and structured content
4. The skill will automatically pick up new `.md` files
